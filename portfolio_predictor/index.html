Import Holdings from a CSV File (on this device)
Private — read locally, never uploaded. Accepts CSV, Excel (.xlsx/.xls/.ods), .tsv, or a Google Sheet (.gsheet). Note: a Google Sheet file is only a link with no data — if you pick one, the sheet must be shared / Published to web so its rows can be fetched; otherwise use File → Download → CSV (or Excel) in Google Sheets. Columns: ticker, shares, price paid (per share). Same ticker on multiple rows (lots) merges into total shares + a weighted-average cost basis, unlocking profit/loss & sell signals.
Import from Online Sheet (CSV / Google Sheets)
CSV needs a symbol (or ticker) column and a shares (or quantity) column. An optional price column lets the sheet drive live prices with no API key — e.g. Google Sheets =GOOGLEFINANCE(A2,"price"). An optional prevclose column enables day-change. In Google Sheets: File → Share → Publish to web → (sheet) → CSV, then paste that link here.

📊 Model & Assumptions▼
Method: Markov Regime-Switching Monte Carlo. Each simulation path transitions between 6 market regimes (Bull, Bear, Crash, Recovery, Sideways, Stagflation) using historically-estimated probabilities. Monthly equity returns are drawn from Normal distributions calibrated to each regime. Your portfolio beta (from Finnhub, default 1.0) scales market sensitivity; an idiosyncratic term captures stock-specific randomness. Bond returns are drawn independently per regime.

PRNG: xoshiro128++ — one independent stream per simulation path
